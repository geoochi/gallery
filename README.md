## usage

###

1. install dependence
```sh
pnpm i
```

2. drag photos (jpg, png or other) into ./public/photos

3. compress photos to webp format

```sh
pnpm refresh
```

4. update repo

```sh
git add . && g commit -m 'update' && g push
```
